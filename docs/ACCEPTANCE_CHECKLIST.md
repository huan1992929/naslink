# NASLink 二期验收清单

## A. 安装和运行

- [ ] DS920+ 套件中心可手动安装 SPK
- [ ] 套件可正常启动、停止和卸载
- [ ] `http://NAS-IP:17890` 可从局域网访问
- [ ] 首次启动要求设置管理员密码
- [ ] 重启套件后配置、绑定和记录保留

## B. DSM 能力

- [ ] `SYNO.API.Auth`、`SYNO.Core.User`、`SYNO.Core.Group`、`SYNO.Core.User.Group` 发现成功
- [ ] DSM 7 管理会话完成 Noise 握手，Core 请求携带 `X-SYNO-TOKEN` 与 `X-SYNO-HASH`
- [ ] 用户和群组数量与 DSM 控制面板基本一致
- [ ] 创建 `naslink_poc_001` 成功
- [ ] 禁用、恢复测试账号成功
- [ ] 加入、移出专用测试群组成功
- [ ] 管理员和 API 账号不受同步修改

## C. 钉钉 / 企业微信通讯录

- [ ] 应用凭据验证成功
- [ ] 根部门及子部门拉取成功
- [ ] 全部可见员工拉取成功
- [ ] 工号、邮箱、部门和在职状态正确
- [ ] 通讯录人数不超过 License 上限
- [ ] 钉钉 Stream 人员事件可进入事件台账
- [ ] 企业微信回调验签、解密和 CorpID 校验成功
- [ ] 人员或部门变动生成 `event-preview` 差异计划
- [ ] 开启自动事件执行后，测试员工变动可生成并完成 `event-auto` 记录

## D. 历史账号匹配

- [ ] 邮箱完全一致可生成 100 分匹配
- [ ] 工号与 DSM 用户名一致可生成 100 分匹配
- [ ] 多名同分候选标记为冲突
- [ ] 一个 DSM 账号不能绑定两名员工
- [ ] 绑定后员工改名不会丢失映射

## E. 生命周期同步

- [ ] 新员工生成“创建账号”预览
- [ ] 调岗生成部门群组差异
- [ ] 离职生成“禁用账号”预览
- [ ] 重新入职生成“恢复账号”预览
- [ ] 不存在删除用户或文件动作
- [ ] 同步失败后可生成仅包含失败项的重试计划

## F. OIDC / Drive Web

- [ ] HTTPS Issuer 可被 DSM 访问且证书可信
- [ ] DSM 可读取 OIDC discovery 和 JWKS
- [ ] Username Claim 设置为 `username`
- [ ] 已绑定员工可从钉钉登录 DSM
- [ ] 离职或未绑定员工登录被拒绝
- [ ] 登录后可打开 Synology Drive Web
- [ ] 企业微信自建应用主页指向 `/launch/wecom/drive`
- [ ] 企业微信内点击应用使用 `snsapi_base` 静默取得成员身份，无需扫码
- [ ] Drive 启动票据使用一次后失效，超过 5 分钟后失效
- [ ] 离职、停用、未在通讯录或未绑定员工均无法进入 Drive Web
- [ ] Drive 启动成功和 OIDC 登录结果写入审计日志
- [ ] 外部请求不能通过启动入口指定任意跳转地址

## G. 审计和授权中心

- [ ] 试用版显示 30 天到期时间和 50 人上限
- [ ] 错误设备指纹的 License 导入被拒绝
- [ ] 篡改 License 签名后导入被拒绝
- [ ] 同步预览、执行、失败和授权操作均有审计日志
- [ ] 激活码只以哈希保存，明文只在创建时显示一次
- [ ] 同一激活码受最大激活次数限制
- [ ] 在线激活返回的 License 可被 SPK 内置公钥验证
- [ ] 续期、吊销、设备迁移有独立记录

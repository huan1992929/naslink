## rc19 引导式同步与 DSM 结果复核

rc19 把原来的“账号匹配 → 同步中心 → 再手工盘点”改为一个四步同步工作台：通讯录、部门范围、账号匹配、DSM 同步。匹配确认后会自动进入同步工作台并生成最新计划；执行时重新读取 DSM 防止使用过期计划，写入后再次读取用户状态和群组成员，只有目标状态被实际读回才标记为成功。人工执行期间定时校准会跳过，避免两个任务同时操作同一账号。

本次实机定位到旧版 `wuyan` 同步异常的直接原因是群组成员写入误用了 `SYNO.Core.User.Group`；rc19 改用 DSM 实际提供的 `SYNO.Core.Group.Member` `add/remove`，并补齐按群组反查成员。实机复核结果：`wuyan` 已启用，描述为“无颜 [NASLink]”，所属群组为 `dept_1、users`；同步工作台显示 1 名通讯录用户、1 个受管部门、1/1 账号已确认，当前计划 0 项，DSM 已一致。

2026-07-18 已无损覆盖安装 `0.3.0-0019 / 0.3.0-rc19`，DSM 返回 `installed_and_started`，套件状态为 `running`。Codex 内置浏览器完成同步工作台、账号盘点和群组盘点验收，DSM 接口能力 8/8 正常，读取到 8 个用户、7 个群组；浏览器控制台 0 错误、0 警告。

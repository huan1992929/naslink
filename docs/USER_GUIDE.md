# NASLink 身份桥安装与使用说明

版本：0.3.0-rc19  
适用：Synology DSM 7、NASLink 0.3.0-0019  
更新日期：2026-07-27

## 1. 产品用途

NASLink 是安装在群晖 DSM 上的企业身份与账号同步套件，用于连接钉钉或企业微信通讯录，并把选定范围内的员工与 DSM 本地账号、部门群组建立可审计的对应关系。

主要能力：

- 读取 DSM 现有用户、群组和 API 能力；
- 读取钉钉或企业微信的部门与员工；
- 优先匹配客户已有 DSM 账号，保留原文件、配额和权限；
- 按预览计划处理入职、调岗、离职和重新入职；
- 为 Synology Drive Web 提供基于 DSM 原生 OIDC 的免登录入口；
- 支持本地授权、在线或离线 License、审计日志和状态备份。

## 2. 使用边界

- NASLink 默认只读，任何 DSM 写入都必须先生成预览并由管理员确认。
- NASLink 不自动删除 DSM 账号、Home 目录、Drive 文件或共享文件。
- Drive Web 免登录不等于桌面版 Synology Drive Client 完全免密。
- 不建议把 NASLink 管理端口 `17890` 直接暴露到公网。
- 正式运行建议使用专用 DSM 服务账号，不长期使用个人管理员账号。

## 3. 安装前准备

### 3.1 群晖环境

- DSM 7.0 或更高版本；
- x86_64 机型安装 `x86_64.spk`；
- 可用的 DSM HTTPS 管理端口，默认 `5001`；
- 需要 Drive 免登录时，先安装并启动 Synology Drive Server；
- 安装人员拥有 DSM 套件中心的手动安装权限。

### 3.2 企业通讯录

选择一个主身份源：

- 钉钉：企业内部应用的 Client ID（AppKey）和 Client Secret；
- 企业微信：Corp ID、Agent ID、Secret，以及配置自建应用和通讯录可见范围的管理员权限。

### 3.3 试运行范围

首次上线只选择一个小部门或少量测试员工。完成账号盘点、匹配、同步预览和写后复核后，再逐步扩大范围。

## 4. 安装、升级与卸载

### 4.1 安装

1. 登录 DSM。
2. 打开“套件中心”。
3. 选择“手动安装”。
4. 上传 NASLink `.spk` 安装包。
5. 阅读第三方套件提示并确认安装。
6. 启动 NASLink。
7. 在浏览器访问 `http://群晖地址:17890/`。

### 4.2 覆盖升级

1. 先在 NASLink“系统授权”页面下载状态备份。
2. 在套件中心再次选择“手动安装”。
3. 上传更高版本安装包并确认覆盖升级。
4. 升级完成后检查页面版本、服务状态、原配置和最近盘点数据。

不要先卸载旧版再安装，除非交付人员明确要求。卸载可能影响本地配置保留方式。

### 4.3 卸载

卸载 NASLink 不应删除 DSM 用户、群组或文件，但会停止通讯录同步和 Drive Web 免登录。卸载前应下载状态备份，并记录当前同步范围和授权信息。

## 5. 第一次登录

首次打开 NASLink 时，需要设置本地管理密码：

- 至少 8 位；
- 必须同时包含字母和数字；
- 建议再包含符号；
- 该密码不是 DSM 密码，也不是钉钉或企业微信密码。

设置完成后点击“前往登录”，使用刚设置的密码进入后台。

## 6. 首次配置向导

首次配置按以下顺序进行：

1. 选择企业通讯录；
2. 连接这台群晖；
3. 连接企业通讯录；
4. 选择同步人员；
5. 确认已有账号；
6. 启用员工同步；
7. 配置 Drive 免登录（可选）。

向导会保存当前进度，可以退出后继续。

## 7. 连接群晖

套件安装在当前群晖时，DSM 地址通常可自动使用本机回环地址，例如 `https://127.0.0.1:5001`。若 DSM 修改过 HTTPS 端口，再按实际端口调整。

需要填写：

- DSM 管理服务账号；
- DSM 密码；
- 是否允许本机自签名证书；
- UAT 安全前缀，仅用于隔离测试写入。

浏览器已经登录 DSM，不代表 NASLink 后台服务自动获得 DSM 会话。NASLink 仍需保存一个用于 API 调用的服务账号凭据。保存后先执行只读盘点，确认能够读取用户和群组。

## 8. 配置钉钉

### 8.1 创建应用

在钉钉开放平台创建企业内部应用，复制 Client ID（AppKey）和 Client Secret。

### 8.2 开通权限

应用至少需要能够读取：

- 企业组织信息；
- 部门列表；
- 部门成员；
- 员工基础信息。

具体权限名称会随钉钉平台版本变化，应以 NASLink“验证钉钉连接”返回的缺失权限为准。应用权限需要企业管理员在钉钉开放平台开通，NASLink 无法代为免配置。

### 8.3 保存与验证

1. 在“设置/连接配置”选择“钉钉”。
2. 填写 Client ID 和 Client Secret。
3. 点击“保存配置”。
4. 点击“验证钉钉连接”。
5. 确认部门读取和员工读取均成功。

如果 Secret 输入框显示“已保存，留空保持原值”，后续修改其他字段时不需要重复输入。

## 9. 配置企业微信

### 9.1 创建自建应用

在企业微信管理后台创建自建应用，记录 Corp ID、Agent ID 和 Secret。

### 9.2 设置可见范围

应用的通讯录可见范围决定 NASLink 能读取的部门与员工。建议先开放一个试点部门，验证完成后再扩大范围。

### 9.3 网页授权与回调

如需企业微信内免登录，还要按 NASLink 页面生成的地址设置：

- 应用主页；
- 网页授权可信域名；
- 通讯录回调 URL、Token 和 EncodingAESKey。

保存后验证企业微信连接和通讯录权限。

## 10. 选择同步范围

组织人数较多时，不建议一次同步全部人员。

推荐：

1. 在“员工与部门/组织同步”选择一个或多个部门；
2. 预览部门负责人、在职员工和子部门数量；
3. 确认仅同步所需人员；
4. 刷新通讯录快照；
5. 检查员工总数是否符合预期。

平台部门通常映射为 DSM 受管群组。部门负责人仍是普通成员身份；如果需要额外权限，应由权限策略或专门群组处理，不能仅凭“负责人”身份自动授予 DSM 管理权限。

## 11. 确认已有账号

账号匹配的首要目标是让员工继续使用原 DSM 账号，避免登录后看不到原 Drive 文件。

NASLink 会比较：

- 工号与 DSM 用户名；
- 企业邮箱及邮箱前缀；
- 姓名、拼音和 DSM 描述；
- 平台用户 ID 与已有固定绑定；
- 所属部门与 DSM 群组。

处理规则：

- 确定性匹配可批量确认；
- 同名员工、多候选账号、管理员账号和多人共用账号必须人工确认；
- 一个个人 DSM 账号不能绑定多个在职员工；
- 不确定时选择“待处理”，不要直接创建新账号；
- 绑定确认后使用稳定的平台用户 ID，不因改名或调岗丢失关系。

## 12. 同步员工

### 12.1 生成预览

账号匹配完成后，到“待处理/同步中心”生成同步预览。预览会列出：

- 将创建的账号；
- 将禁用的账号；
- 将创建的部门群组；
- 将加入或移出的群组成员；
- 冲突和高风险项；
- 不执行的保护账号。

### 12.2 执行与复核

检查预览后输入页面要求的确认词，执行同步。系统写入完成后会自动重新盘点，显示每项验证结果。

“匹配成功”只表示建立平台用户与 DSM 账号的绑定，不代表已经执行同步。

### 12.3 人员生命周期

- 入职：创建或绑定 DSM 账号，加入受管部门群组；
- 调岗：加入新部门群组，旧群组是否移除由策略决定；
- 离职：默认禁用已绑定账号并保留文件；
- 重新入职：平台用户 ID 相同时恢复原绑定；
- 多部门：加入多个有效部门群组；
- 改名：更新显示信息，不改变固定绑定。

## 13. 配置 Synology Drive Web 免登录

### 13.1 前提

- Synology Drive Server 已安装并运行；
- 员工已绑定到启用的 DSM 账号；
- DSM 已配置 NASLink 为 OIDC 身份提供方；
- Issuer 地址能被员工浏览器和 DSM 正确访问；
- Redirect URI 与 DSM 中的配置完全一致。

### 13.2 配置

在“设置 → DSM → Drive 免登”中填写或生成：

- Issuer 公共地址；
- DSM Client ID；
- DSM Client Secret；
- DSM Redirect URI；
- Synology Drive Web 地址。

完成后从钉钉或企业微信自建应用入口测试。先用试点员工验证账号、群组、Drive 权限和退出流程，再开放给更多人员。

## 14. 日常使用

- 首页：查看服务、DSM、授权和待处理状态；
- 员工与部门：查看同步范围、员工状态和部门关系；
- 待处理：处理冲突、预览计划、执行同步和查看历史；
- 设置：维护 DSM、身份源、同步策略、Drive 和授权；
- 帮助：从右上角打开本说明的精简网页版本；
- 退出：完全退出 NASLink 管理会话，返回登录界面。

建议初期让人员变动事件只生成待确认计划，不自动执行高风险写入。

## 15. 授权

NASLink 支持：

- 本地试用；
- 在线激活码；
- 纯内网离线 License；
- 按设备、用户数、身份源和功能模块授权。

在线激活时，客户端向授权中心提交设备指纹并取得数字签名 License；离线环境可导出申请信息，由授权中心签发后再导入。License 到期不应删除或破坏 DSM 现有数据。

## 16. 常见问题

| 现象 | 可能原因 | 处理方法 |
|---|---|---|
| 钉钉凭据已填仍提示为空 | 未保存、Secret 未进入当前表单状态 | 先保存配置，再验证；确认 Client ID 无前后空格 |
| 钉钉部门或员工读取失败 | 通讯录权限未开通或应用未发布 | 在钉钉开放平台补齐权限并重新发布 |
| 匹配后 DSM 没有新账号 | 匹配没有执行写入 | 到同步中心生成预览并确认执行 |
| DSM 盘点看不到群组 | 当前在账号视图或群组接口未读取成功 | 切换群组盘点，查看 DSM API 能力详情 |
| 员工看不到原 Drive 文件 | 绑定到了错误或新建的 DSM 账号 | 停止同步，改绑原账号，不删除或迁移文件 |
| DSM 连接失败 | 地址、端口、证书或权限不正确 | 检查 5001 端口、服务账号和自签名证书选项 |
| Drive 免登录失败 | OIDC 参数或回调地址不一致 | 逐项核对 Issuer、Client ID、Secret 和 Redirect URI |
| 页面仍显示旧版本 | 套件资源未覆盖或浏览器缓存 | 检查套件版本、重启服务并强制刷新浏览器 |

## 17. 上线验收清单

- [ ] 页面显示的 NASLink 版本与安装包一致；
- [ ] 服务在线且重启后自动恢复；
- [ ] DSM 用户、群组只读盘点成功；
- [ ] 身份源部门和员工读取成功；
- [ ] 同步范围仅包含试点人员；
- [ ] 已有账号匹配经过管理员确认；
- [ ] 同步预览无未处理冲突；
- [ ] 写入后自动复核通过；
- [ ] 原 DSM 用户文件和权限未受影响；
- [ ] 离职测试只禁用账号，不删除文件；
- [ ] Drive Web 免登录以试点账号验证成功；
- [ ] 状态备份已下载；
- [ ] NASLink 管理端口未直接暴露公网。

## 18. 获取支持时需要提供的信息

为便于排查，可提供：

- NASLink 版本；
- DSM 版本和群晖机型；
- Synology Drive Server 版本；
- 错误发生的页面和操作步骤；
- 脱敏后的错误信息；
- 同步任务编号或时间。

不要发送 DSM 密码、App Secret、企业员工完整通讯录、License 私钥或未脱敏的状态备份。

# DS920+ 家庭测试指南

## 1. 测试前

1. 确认机器型号是 **DS920+**（x86_64），记录 DSM 与 Synology Drive Server 完整版本；如实际不是 DS920+，先不要安装；
2. 导出 DSM 系统配置备份；
3. 新建临时管理员 `naslink_poc_admin`，不要复用日常管理员密码；
4. 暂时不要在生产群晖安装；
5. 不要把 5001 或 17890 直接映射到公网。

## 2. 安装

1. 打开“套件中心 → 手动安装”；
2. 选择 `NASLink-0.3.0-0019-x86_64.spk`；
3. DSM 会提示第三方套件警告，确认安装到测试机；
4. 套件启动后访问 `http://NAS局域网IP:17890`；
5. 首次打开设置并确认 NASLink 本地管理员密码；该密码只用于 NASLink，不是 DSM 密码。

如 DSM 已启用防火墙，需新增一条**仅限局域网网段**访问 TCP `17890` 的规则。不要将该端口转发到公网。

## 3. 第一轮只读验证

1. 填写 DSM 地址和临时管理员账号；
2. 如测试机使用自签名证书，临时开启“允许自签名证书”；
3. 保存后点击“连接并盘点”；
4. 确认报告中出现 `SYNO.Core.User` 与 `SYNO.Core.User.Group`；
5. 对照 DSM 控制面板核对用户数和群组数。

## 4. 测试写操作

只允许创建 `naslink_poc_` 前缀账号。建议顺序：

1. 预览创建 `naslink_poc_001`；
2. 输入确认词并执行；
3. 在 DSM 控制面板确认账号；
4. 测试加入一个专用测试群组；
5. 测试禁用，再重新启用；
6. POC 当前不提供删除功能，测试结束后由管理员在 DSM 手动清理。

## 5. 身份源与 OIDC

第一轮家庭测试先完成“安装、启动、DSM 只读盘点、测试账号写入”。OIDC 的 Issuer 必须是 DSM 可访问且证书可信的 HTTPS 地址；当前 POC 不会自动修改 DSM 反向代理。测试 SSO 前，可在 DSM“登录门户 → 高级 → 反向代理服务器”建立 HTTPS 入口，再将请求转发到 `http://127.0.0.1:17890`。

1. 在 NASLink 选择钉钉或企业微信作为主身份源；
2. 在对应平台创建企业内部/自建应用并授予通讯录权限；
3. 钉钉填写 Client ID、Client Secret；企业微信填写 Corp ID、Agent ID、Secret；
4. 企业微信将 NASLink 显示的 `/events/wecom` 配成通讯录回调，并填写相同 Token 与 EncodingAESKey；
5. 钉钉在开放平台启用 Stream 模式人员/部门事件，保存配置后重启套件以建立长连接；
6. 在 NASLink 建立“平台稳定 ID → DSM 用户名”绑定；
7. 在 DSM“控制面板 → 域/LDAP → SSO Client”启用 OIDC；
8. Well-known URL 填 NASLink 页面显示的地址，Username Claim 填 `username`；
9. 使用无痕窗口验证登录，再验证 Drive Web。

如测试企业微信工作台免登，在 NASLink 中填写 Drive Web 地址，复制“自建应用主页”到企业微信应用后台，并按 [企业微信自建应用接入 Synology Drive Web](WECOM_DRIVE_SSO.md) 完成可信域名、可见范围和一次性票据测试。

## 6. 通讯录与账号匹配

1. 先点击“验证应用凭据”；
2. 再在“组织同步”拉取通讯录；
3. 核对部门数、在职员工数和 License 上限；
4. 执行“重新计算匹配”；
5. 只批量确认 100 分且无冲突的账号；
6. 同名、多候选、管理员账号必须逐条处理；
7. 为需要同步的部门选择已存在的 DSM 专用群组。

## 7. 生命周期同步

1. 第一次不要开启“创建未匹配账号”和“离职禁用”；
2. 生成同步预览，确认差异为 0 或全部符合预期；
3. 选择 1～2 个 `naslink_poc_` 测试账号做入职、调岗、离职演练；
4. 核对成功后再开启正式账号创建；
5. 离职策略建议最后开启，并先逐条检查预览清单；
6. 系统只禁用离职账号，不删除 Home、Drive 文件或账号。

## 8. 人员变动与授权中心

1. 在测试平台新增、调岗、停用一个测试员工；
2. 检查“系统状态备份”中的 `source_events` 是否记录事件；
3. 检查同步中心是否出现 `event-preview`，确认后再执行；
4. 完成至少一轮人工确认后，才考虑开启“人员变动事件自动执行”；生产首次启用应保持 `create_missing` 与 `disable_departed` 分阶段开放；
5. 在线激活时填写授权中心 URL 与激活码；纯内网环境继续导入离线 License；
6. 验证错误设备、超次数激活码和被吊销 License 均不能重新签发。

## 9. 回传测试结果

请回传：

- “账号盘点”页的能力标签与用户数截图；
- DSM 与 Drive 完整版本；
- 首个失败步骤和错误码；
- 不要回传密码、SID、SynoToken、Client Secret 或完整用户数据。

## 10. 非 IT 管理员首次配置验收

1. 初始化后应进入“开始使用 NASLink”向导，而不是技术菜单；刷新并重新登录后应恢复当前步骤；
2. DSM 步骤只能执行只读盘点；身份源步骤提示部门和员工读取权限；
3. 选择范围和安全账号确认不会写入 DSM；管理员、保护账号、冲突和重复绑定不得被批量接受；
4. 生成预览后，使用 NASLink 管理密码启用同步；预览陈旧、密码错误或群晖重盘点失败必须拒绝写入；
5. Drive 免登录可选择“稍后配置”，且不应阻塞员工同步；
6. 下载或查看支持诊断时，确认其中没有密码、Secret、Token、姓名、邮箱、手机号或带凭据 URL。
